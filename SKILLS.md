# Skills

| Skill | Use for |
|---|---|
| `tlc-spec-driven` | The cycle engine: Specify → Design → Tasks → Execute, plus the independent Verifier; owns `.specs/` |
| `create-adr` | Recording an architecture decision after it's made (`docs/adr/`) |
| `create-rfc` | Proposing roadmaps or significant changes needing alignment |
| `create-technical-design-doc` | Design docs for large multi-cycle efforts |
| `grilling` | Stress-testing a plan or decision before committing to it |
| `skill-architect` | Building new project skills |
| `hyperf-best-practices` | Hyperf/Swoole coroutine-runtime rules for writing and reviewing PHP in this service |
